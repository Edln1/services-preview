# Synapses Services preview

Public GitHub Pages preview of the Synapses Services homepage and Still Home's home-cleaning website.

The primary deployment is maintained in [Edln1/services](https://github.com/Edln1/services), with the services homepage at `/` and Still Home at `/stillhome/`. This preview uses the standard github.io address while custom-domain DNS and HTTPS activation complete. The estimate calculator runs locally and does not submit bookings. Both preview pages are marked noindex to avoid duplicate search listings.
